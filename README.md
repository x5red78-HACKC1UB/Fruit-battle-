# Fruit-battle-
My game from scratch adapted into vscode!



Click the fruit you want!
Move with wasd
Use Z, X, C, and V to do fruit moves
Use the number keys to spawn enemies(1,2,3)
Inspired by Blox Fruits, which is inspired by One Piece.
I intentionally didn't add player hp and you start with no fruit
(Putting this here bc apparently putting it in the game got the game rejected?)
